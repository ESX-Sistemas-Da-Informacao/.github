## Como a gente trabalha

- **Tudo monitorado.** Servidor, backup, certificado e link têm alerta — com Zabbix, não com sorte.
- **Backup que restaura.** Cópia cifrada fora do servidor, verificada toda semana e testada de verdade.
- **Tudo versionado.** Cada sistema tem histórico no Git, deploy controlado e segredos fora do código.
- **Documentado.** O ambiente de cada cliente fica registrado — se alguém sair de férias, a TI continua funcionando.
